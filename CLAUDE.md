# omuk-ui

## Baseline target

This project's Baseline target is Baseline Newly available.

- Use a web platform feature when it is Baseline Newly available or Widely available.
- Give a fallback for a feature that is not Widely available. Use `@supports` or progressive enhancement.
- Do not use a feature with Limited availability unless it is a progressive enhancement only.
- Do not add a headless library (Base UI, Radix, React Aria, Floating UI). Build each component on native HTML and CSS.
